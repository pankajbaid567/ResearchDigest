## 🚀 Quick Start

The app is already running! Open your browser to:
- **Local**: http://localhost:8501
- **Network**: http://10.7.17.139:8501

### How to Use

1. **Upload documents** (PDF/text) OR **enter text directly**
2. **Configure** in sidebar:
   - Number of topics: 5
   - Keywords per topic: 10
   - Summary sentences: 5
   - Method: **LDA (Gensim)** or K-Means
3. **Click** "🚀 Run Analysis"
4. **View results** in 6 tabs!

## ⚠️ Minor Notes

**PDF Support**: To enable PDF uploads, install:
```bash
pip install PyPDF2 pdfplumber
```

**spaCy (Optional)**: For better lemmatization:
```bash
python -m spacy download en_core_web_sm
```

Both are optional - the system works perfectly with NLTK!
